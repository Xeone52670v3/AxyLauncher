# Project Rules (AxyLauncher)

## UI Copy Style
- Write short, clean **title + plain description** in UI cards, buttons, and settings.
- Do **not** describe internal implementation details, supported file formats, or technical mechanics in user-facing UI descriptions.
  - Good: `Updates` / `Check and install updates`
  - Bad: `Updates (GitHub)` / `Check and install updates via GitHub Releases (Windows MSI/EXE, Linux AppImage/Flatpak, macOS DMG; Linux system packages are updated manually).`

## Versioning (`x.y.z`)
- `x` — major milestone when the launcher is 100% ready / huge changes.
- `y` — significant feature updates.
- `z` — minor fixes.
